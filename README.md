ToDo List Web App
This project is a dynamic ToDo List application built using HTML, CSS, and JavaScript. It offers a clean, responsive interface where users can quickly add, mark, and delete tasks, making it easy to manage daily responsibilities.

Features
Add & Delete Tasks: Quickly add new tasks and remove completed ones.
Mark Tasks as Complete: Toggle tasks as completed for better task management.
Responsive Design: A mobile-friendly layout that adjusts to various screen sizes.
Local Storage: Persist tasks on the browser so they remain even after the page is refreshed.
Interactive UI: Simple, intuitive, and visually appealing interface for a seamless user experience.
Getting Started
Prerequisites
A modern web browser (e.g., Chrome, Firefox, Edge, Safari).

Usage
Add a Task: Type your task into the input field and click the "Add" button.
Mark as Completed: Click on a task to toggle its completion status.
Delete a Task: Use the delete button next to each task to remove it.
This project serves as a great foundation for understanding DOM manipulation, event handling, and the basics of building interactive web applications.
